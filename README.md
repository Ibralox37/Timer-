# Timer Challenge

Ein Geschicklichkeitsspiel von **VORIX – WE CREATE GAMES**.

Stoppe den Timer genau auf die Zielzeit. Spiele Challenges, sammle 100%-Treffer und tritt in der globalen Rangliste gegen Spieler auf der ganzen Welt an.

**Jetzt spielen:** https://ibralox37.github.io/Timer-/

Das Spiel läuft im Browser und lässt sich auf Handy und PC als App installieren („Zum Startbildschirm hinzufügen" bzw. Installieren-Symbol in der Adresszeile).

## Funktionen

- 7 Spielmodi: Normal, Blind, Challenge, Challenge Blind, Stoppe bei 1 / 5 / 10 Sekunden
- Online-Konten: Anmeldung mit Benutzername und Passwort, auf jedem Gerät
- Globale Rangliste mit serverseitigem Cheat-Schutz
- Gastmodus ohne Konto
- Wählbare Farbdesigns und Neon-Modus
- Freunde-Modus zum abwechselnden Spielen an einem Gerät
- Offline spielbar (installierte App)
